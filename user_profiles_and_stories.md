# Protisruti — User Profiles & User Stories

## 1. Purpose

This document defines the primary users of Protisruti, their needs,
challenges, goals, and how they are expected to use the platform.

Protisruti will initially focus on two primary user groups:

1. Children and students
2. Women seeking education, skills, and opportunities

---

# 2. User Profile — Student

## Name

Amina

## Age

13 years old

## User Type

Student

## Background

Amina is a student who sometimes struggles to understand difficult
academic concepts. She has access to a smartphone or computer but does
not always have access to a private tutor.

## Main Challenges

- Difficulty understanding difficult subjects
- Limited access to personalized tutoring
- Difficulty knowing what to study
- Limited opportunities for additional practice
- Difficulty identifying weak areas
- Difficulty maintaining a consistent study schedule

## Goals

Amina wants to:

- Understand difficult school subjects
- Improve her academic performance
- Practice more questions
- Develop a consistent study routine
- Become more confident in learning

## How Protisruti Can Help

Protisruti can provide:

- Personalized explanations
- Step-by-step learning assistance
- Practice questions
- AI-generated quizzes
- Personalized study plans
- Reading assistance
- Progress tracking
- Goal setting

---

# 3. Student User Stories

## User Story 1 — Ask a Question

**As a student, I want to ask Protisruti questions about subjects I
struggle with so that I can understand difficult concepts.**

### Acceptance Criteria

- The student can enter a question.
- Protisruti provides an understandable answer.
- The response is appropriate for the student's learning level.
- The student can ask follow-up questions.

---

## User Story 2 — Get a Simple Explanation

**As a student, I want Protisruti to explain difficult concepts in simple
language so that I can understand them more easily.**

### Acceptance Criteria

- The student can request a simpler explanation.
- Protisruti can provide examples.
- Protisruti can break complicated concepts into smaller parts.

---

## User Story 3 — Generate a Quiz

**As a student, I want Protisruti to generate practice questions so that I
can test my understanding.**

### Acceptance Criteria

- The student selects a topic.
- The student selects a difficulty level.
- Protisruti generates questions.
- The student can submit answers.
- Protisruti provides feedback.

---

## User Story 4 — Create a Study Plan

**As a student, I want Protisruti to create a study plan based on my goal
and available time so that I can study consistently.**

### Acceptance Criteria

- The student enters a learning goal.
- The student provides available study time.
- The student selects a target period.
- Protisruti generates a structured study plan.

---

## User Story 5 — Track Progress

**As a student, I want to see my learning progress so that I can
understand how much I have accomplished.**

### Acceptance Criteria

- Completed activities are recorded.
- Quiz results are stored.
- The student can view basic progress information.

---

# 4. User Profile — Woman

Nadia

## Age

24 years old

## User Type

Adult learner

## Background

Nadia wants to improve her education and digital skills so that she can
increase her future educational and employment opportunities.

experience.

- Difficulty finding trustworthy educational resources

## Goals

Nadia wants to:

- Improve her computer skills
- Learn programming
- Improve English communication
- Find free educational resources
- Discover scholarships
- Understand possible career paths
- Create a structured learning plan
- Build confidence

## How Protisruti Can Help

Protisruti can provide:

- Personalized learning pathways
- Digital skills training
- English practice
- Programming guidance

- Educational guidance
- Scholarship information
- Free learning resources

- Progress tracking

# 5. Woman User Stories

## User Story 1 — Choose a Learning Goal

**As a woman, I want to choose a learning goal so that Protisruti can
provide guidance that matches my needs.**

### Acceptance Criteria

- The user can select or enter a learning goal.
- The user can describe their current skill level.
- Protisruti uses this information to personalize recommendations.

---

## User Story 2 — Learn Digital Skills

**As a woman with limited computer experience, I want to learn digital
skills step by step so that I can become more confident using technology.**

### Acceptance Criteria

- The user can select a digital skill.
- Protisruti provides beginner-friendly learning material.
- Protisruti can create a learning path.
- The user can track completed activities.

---

## User Story 3 — Learn Programming

**As a beginner, I want Protisruti to create a programming learning path
so that I can learn programming without feeling overwhelmed.**

### Acceptance Criteria

- The user can select a programming language.
- The user can specify their current level.
- Protisruti generates a structured learning path.
- Protisruti provides practice activities.

---

## User Story 4 — Improve English

**As a woman who wants to improve her English, I want to practice
communication and receive feedback so that I can become more confident.**

### Acceptance Criteria

- The user can practice writing or conversation.
- Protisruti can provide grammar suggestions.
- Protisruti can provide vocabulary suggestions.
- Protisruti explains mistakes in understandable language.

---

## User Story 5 — Explore Careers

**As a woman who is uncertain about her career direction, I want to
explore career options based on my interests and skills so that I can
make better-informed educational decisions.**

### Acceptance Criteria

- The user can describe interests and skills.
- Protisruti provides possible career areas.
- Protisruti explains relevant skills.
- Protisruti suggests learning resources.

---

## User Story 6 — Find Educational Opportunities

**As a woman looking for educational opportunities, I want Protisruti to
help me discover scholarships, free courses, and training programs so
that I can find opportunities that may otherwise be difficult to locate.**

### Acceptance Criteria

- The user can enter an educational goal.
- The user can specify relevant interests.
- Protisruti can present relevant opportunities.
- Opportunity information should be verifiable.

---

## User Story 7 — Track Learning Progress

**As a woman learning a new skill, I want to track my progress so that I
can see my improvement and remain motivated.**

### Acceptance Criteria

- Completed activities are recorded.
- Progress can be displayed.
- Quiz scores can be recorded.
- Users can see progress toward learning goals.

---

# 6. Common User Stories

The following features will be available to both students and women.

## Personalized Study Plan

**As a learner, I want Protisruti to create a study plan based on my
available time and learning goals so that I can study consistently.**

## AI Educational Support

**As a learner, I want to ask Protisruti questions and receive
understandable explanations so that I can learn independently.**

## Practice and Assessment

**As a learner, I want to practice what I have learned through quizzes
and exercises so that I can identify areas where I need improvement.**

## Goal Tracking

**As a learner, I want to set educational goals and track my progress so
that I can stay motivated.**
