# Contributing to Protisruti

Thank you for your interest in contributing to Protisruti!

Protisruti is an AI-powered educational and empowerment platform designed to support women and children through personalized learning, skill development, opportunities, and progress tracking.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them locally.
4. Commit your changes with a clear commit message.
5. Push your branch to GitHub.
6. Open a Pull Request describing your changes.

## Contribution Guidelines

When contributing, please:

- Keep the code simple, readable, and well documented.
- Follow the existing project structure.
- Test new features before submitting a Pull Request.
- Do not commit passwords, API keys, database files, `.env` files, or other sensitive information.
- Respect user privacy and responsible AI principles.
- Keep educational content appropriate and safe for the intended users.

## Reporting Issues

If you find a bug or have an idea for improvement, please open a GitHub Issue and provide:

- A clear description of the issue or suggestion.
- Steps to reproduce the issue, if applicable.
- Any relevant error messages or screenshots.

## Feature Suggestions

Feature suggestions are welcome. Please explain:

- What problem the feature would solve.
- Who would benefit from it.
- How you think it could improve Protisruti.

Thank you for helping improve Protisruti!
